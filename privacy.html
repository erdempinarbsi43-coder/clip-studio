Privacy Policy

Last updated: 31 October 2026

Clip Studio ("the tool") is the private publishing tool of the account owner's short-form video pages. It is used only by the owner.

Which data the tool uses

With the owner's permission (OAuth login with TikTok, Instagram/Meta or Google), the tool:

  • uploads the owner's own clips and captions to the owner's own TikTok, Instagram and YouTube accounts;
  • reads basic information of these accounts (display name, profile) and of their posts (link, publish time, view counts) to record what was posted.

The tool does not collect data about other people.

How the data is stored

Access tokens and post records are stored only on the owner's own computer. The tool stores no data on external servers.

Sharing

The tool does not sell, share or transfer any user data to third parties and does not use it for advertising. Use of data from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

  • TikTok: TikTok app → Settings and privacy → Security and permissions → Apps and services permissions.
  • Instagram: instagram.com → Settings → Apps and websites.
  • Google/YouTube: Google account permissions.

Locally stored data is deleted by removing the tool's token files.
